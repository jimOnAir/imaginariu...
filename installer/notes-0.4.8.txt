Imaginarium 0.4.8 — установщик сам смотрит, что уже есть, и ставит выбранное

• Новый шаг «Что установить». После выбора папки установщик проверяет компьютер и показывает каждую программу и модель: что уже стоит, какая версия и где, что нужно скачать и сколько. Уже установленное не скачивается повторно. Устаревшее помечено «обновить»: старая версия ComfyUI, файл модели другой версии, нет загрузчика для FLUX.2 и Qwen-Image.
• Галочки по каждому компоненту. Кнопки «Быстрая», «Полная — всё» и «Облегчённая» расставляют их сами. По умолчанию — «Полная», в ней отмечено всё; без видеокарты NVIDIA — «Облегчённая». Без Node.js, интерфейса и Blender студия не работает, их галочки не снимаются; то, без чего не работает отмеченное, отмечается само. Внизу — сколько скачать и сколько свободно на диске.
• Ставится ровно отмеченное, само и без вопросов, всё — в папку программы. Недоступное на этом компьютере (например, Pixal3D без NVIDIA RTX) показано серым с причиной.
• Если проверка компьютера не удалась, установщик ставит выбранный набор целиком, как раньше.

Бесплатно — для личного и другого некоммерческого использования. Подписка (5 $/мес или 49 $/год; 490 ₽ / 4800 ₽) — коммерческое использование и каждое обновление в день выхода. Один ключ — один компьютер.
У кого стоит 0.4.5–0.4.7 без подписки: в студии появится «Бесплатное обновление — установить», нажмите «Обновить бесплатно». Чтобы доставить недостающие программы и модели, запустите новый установщик https://github.com/Snodrod/AstraForge/releases/latest в ту же папку: он найдёт уже установленное и предложит только недостающее. Проекты, модели и настройки сохранятся.

Imaginarium 0.4.8 — the installer checks what you already have and installs what you choose

• New step "What to install". After you pick the folder, the installer checks the computer and lists every program and model: what is already installed, which version and where, what needs to be downloaded and how big it is. Anything already installed is not downloaded again. Outdated items are marked "update": an old ComfyUI, a model file of a different version, a missing loader for FLUX.2 and Qwen-Image.
• A checkbox for each component. The "Quick", "Full — everything" and "Lite" buttons set them for you. The default is Full, where everything is ticked; without an NVIDIA card it is Lite. The studio cannot work without Node.js, the interface and Blender, so they cannot be unticked; anything a ticked item needs is ticked automatically. The bottom line shows how much to download and how much disk space is free.
• Exactly what is ticked gets installed, by itself and without questions, all into the program folder. Anything this computer cannot run (for example, Pixal3D without an NVIDIA RTX card) is greyed out with the reason.
• If the computer check fails, the installer installs the chosen set as a whole, as before.

Free for personal and other noncommercial use. Subscription ($5/month or $49/year): commercial use and every update on release day. One key — one computer.
On 0.4.5–0.4.7 without a subscription: the studio shows "Free update — install"; press "Update for free". To add missing programs and models, run the new installer https://github.com/Snodrod/AstraForge/releases/latest into the same folder: it finds what is installed and offers only what is missing. Projects, models and settings are kept.
