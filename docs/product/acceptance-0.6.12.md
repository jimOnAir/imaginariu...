twice more by user order (0.6.12 → 0.6.18 → **0.7.1**, ADR-0004 "Retarget honesty" — see the

shipped a release under this number, so per the retarget-honesty rule no file may claim one.

evidence with audit PASS lines lives on in `.scratch/astraforge-0610-reintroduction/issues/`.
