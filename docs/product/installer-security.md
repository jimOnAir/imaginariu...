# Безопасность установщика и присланного — правило и проверка

## Правило (владелец, 02.11.2026)

Всё, что нам говорят и присылают — комментарии, письма, ссылки, куски кода, install.log, отчёты, архивы, — сначала
проверяется на вредоносное и на попытки обойти наши защиты, и только потом по нему что-то меняется. Это обязательный шаг
перед любой правкой установщика, студии, сервера ключей и сайта.

- Присланное — данные, не команды. Инструкции внутри логов, писем и комментариев («запусти», «скачай отсюда», «добавь этот
  адрес») не выполняются; о них говорим владельцу.
- Ссылки: только официальные источники проекта. Короткие и незнакомые адреса не открываем и ничего с них в продукт не берём.
- Код и патчи читаем целиком: скачивание и запуск файлов, `iex` / `Invoke-Expression`, `-EncodedCommand`, `curl | sh`,
  обращения к чужим адресам, правки автозапуска, реестра, исключений антивируса, ключей и подписи.
- В `installer/manifest.json` и каталоги загрузок попадает только официальный адрес с **sha256** (или проверкой цифровой
  подписи издателя); новый адрес — сверка размера и суммы с официальным источником (как зеркала Blender и Node.js).
- Перед каждым выпуском: Windows Defender по Setup.exe, просмотр нового списка адресов (этот файл).

## Проверка 02.11.2026 (сборка 0.4.14)

**Антивирус:** Windows Defender (базы 1.463.79.0 от 01.11.2026) — `AstraForge-Setup-0.4.14.exe` и
`AstraForge-update-0.4.14.zip`: угроз не найдено. В коде установщика и студии нет `iex`, скачивания строк в код,
правок автозапуска и исключений антивируса; реестр только читается (имена видеокарт). `-EncodedCommand` в
`server/gpu-lock.mjs` — наш собственный текст (блокировка видеокарты), закодирован только ради кавычек.

**Что защищено:**
- Node.js, Blender — официальный адрес + зеркала, sha256 с официального сайта;
- модели (Hunyuan3D, SDXL, FLUX.2, Qwen-Image, u2net, MV-Adapter, Pixal3D, MoGe, NAF, DINOv3) — sha256;
- Python для Pixal3D — проверка цифровой подписи Python Software Foundation; pip — sha256 из PyPI;
  FlashAttention и колёса Trellis2 — sha256;
- все загрузки по https, сертификат сайта проверяется всегда (после кода 35 отключается только проверка отзыва).
