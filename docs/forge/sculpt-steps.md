# Шаг sculpt — скульптурные операции над сеткой без окна

Шаг Кузницы `sculpt` (`scripts/blender/steps/sculpt.py`) делает над сеткой то, что делают кисти
скульпта, но как повторяемые операции с маской области: сгладить, раздуть, сдвинуть, выровнять,
перенести форму с другой сетки, сделать ремеш и симметрию. Окно Blender не нужно: всё идёт через
`bmesh`, `numpy` и модификаторы (`bpy.ops.sculpt` требует вьюпорт и не используется).

Вызывается тремя способами:

- конвейер: `{"step": "sculpt", "params": {"ops": [...]}}` (в `forge_run`, пресетах, API `/api/forge`);
- MCP (Claude): инструменты `sculpt` и `sculpt_transfer`, см. ниже;
- вкладка «Скульпт» (SculptGL): правка рукой, затем `transfer` кладёт форму на рабочую модель.

Файлы: `scripts/blender/steps/sculpt.py`, `scripts/blender/tests/test_sculpt.py`,
регистрация — `server/forge-steps.mjs` (шаг и пресет `sculpt_refine`), перенос по ассету — небольшая
вставка в `server/forge-pipeline.mjs`, MCP — `ai/mcp/server.mjs`.

## Вход, выходы, система координат

- Вход: `.blend` предыдущего шага (предпочтительно: сокеты, риг и клипы остаются как есть) или
  GLB/FBX/OBJ/STL.
- Выходы: `glb` (`sculpt.glb`), `mesh` (тот же файл), `blend` (`sculpt.blend`), `preview`
  (`preview.png`: до | после, спереди и три четверти, один кадр).
- Модель **не нормализуется**: координаты остаются как в файле, в метрах, Z вверх, лицом в −Y.
  `region.center`, `offset`, `plane` — в этой системе. У рига это поза покоя (bind), а не поза
  первого кадра клипа. Габариты и рост — `inspect` или `cleanup`.
- Сетки с разрезанными по UV-швам вершинами (так делает импорт glTF) работают как цельные: шаг
  сваривает совпадающие позиции «на лету», сдвиг записывается во все копии вершины, швы не рвутся.

## Параметры шага

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `ops` | — (обязателен) | список операций по порядку |
| `symmetry` | `none` | `x` / `y` / `z` / `none`: зеркалить маску и операцию (мировая плоскость через ноль); у операции может быть своя `symmetry` |
| `keep_uv` | `true` | UV обязаны уцелеть; `remesh` при UV отклоняется (ошибка до начала работы), `false` разрешает и стирает UV |
| `preserve_rig` | `true` | арматура, кости, клипы и веса остаются; `false` — риг отбрасывается |
| `objects` | все сетки | имена сеток, с которыми работать |
| `shade_auto_smooth_deg` | `40` | нормали затронутых сеток пересчитываются (пользовательские сбрасываются, гладкость по углу); `null` — только сброс |
| `tolerance_m` | 0,01 размера | предел проверки `transfer_max_dist_m` (для среднего — четверть) |
| `preview`, `preview_size` | `true`, 512 | лист «до / после» |

## Области (`region`)

Маска даёт вес 0…1 каждой точке; операция действует с этим весом. Без `region` — вся сетка.

| `type` | Поля | Вес |
|---|---|---|
| `all` | — | 1 |
| `sphere` | `center`, `radius`, `falloff` | от центра к краю по `falloff` |
| `box` | `center`, `extents` (половины сторон `[hx, hy, hz]` или число), `feather` (0,3), `falloff` | 1 в ядре, к грани спад на долю `feather` |
| `vertex_group` | `name`, `falloff` | вес группы, подправленный кривой |
| `bone` | `name`, `children` (false), `radius`, `falloff` | веса группы кости (и потомков при `children`); если у сетки нет такой группы — расстояние до отрезка кости в пределах `radius` (по умолчанию половина длины кости) |

`falloff`: `smooth` (сглаженная ступень, по умолчанию), `linear`, `sharp` ((1−t)², остро у центра),
`constant` (1 внутри, 0 снаружи). `invert: true` берёт 1 − вес.

**Симметрия.** Маска считается дважды: как есть и зеркально. Для групп и костей зеркало — группа с
парным именем (`arm.L` ↔ `arm.R`, `mixamorig:LeftArm` ↔ `RightArm`), иначе — поиск зеркальной
вершины. Векторы (`grab.offset`, плоскость `flatten`, центр `pinch`) зеркалятся тоже. На плоскости
симметрии зоны накладываются и усредняются, а не применяются дважды.

## Операции

Точечные (топология не меняется):

| `op` | Параметры | Что делает |
|---|---|---|
| `smooth` | `iterations` 5, `factor` 0.5, `pin_boundary` true | лапласово сглаживание; открытые края неподвижны |
| `relax` | `iterations` 5, `factor` 0.5, `keep_volume` true, `pin_boundary` true | сглаживание Таубина + поправка объёма вдоль нормалей (замкнутые сетки): без усадки |
| `inflate` | `amount` (м) | сдвиг вдоль нормали вершины на `amount` при весе 1 |
| `deflate` | `amount` (м) | то же внутрь |
| `flatten` | `strength` 1, `iterations` 1, `plane {point, normal}` | к плоскости: заданной или лучшей по региону |
| `pinch` | `amount` 0.3, `center`, `radial` false | к центру региона вдоль поверхности (`radial` — в 3D) |
| `expand` | то же | от центра |
| `grab` | `offset [x, y, z]` (м) | сдвиг региона на вектор, вес спадает по `falloff` |
| `transfer` | `source_asset` (UUID) \| `source` (путь, только CLI), `method` `project`\|`nearest`, `strength` 1, `align` `auto`\|`none`\|`bbox`, `seam_smooth` 2 | перенос формы с другой сетки, см. ниже |

Топологические:

| `op` | Параметры | Что делает |
|---|---|---|
| `remesh` | `mode` `voxel`\|`quad`, `voxel_size` (м; 0,0033 высоты), `target_faces` (quad), `adaptivity` | перестраивает сетку целиком (регион игнорируется); стирает UV и цвет вершин; веса рига возвращаются переносом с исходной сетки (ближайшая поверхность). `quad` — QuadriFlow, при неудаче откат на `voxel` с предупреждением |
| `subdivide` | `cuts` 1…3, `threshold` 0.5 | делит рёбра, оба конца которых имеют вес ≥ порога; UV и веса интерполируются, сетка остаётся замкнутой (рёбра соседей достраиваются) |
| `decimate` | `ratio` 0.01…1 | область оставляет `ratio` своих треугольников (коллапс-децимация с группой вершин); вне области геометрия меняется мало, но не гарантированно нулю |
| `symmetrize` | `axis` x, `direction` `+`\|`-` | рассекает по плоскости и зеркалит: `+` копирует сторону + на сторону −. Веса зеркальной половины переезжают в парные группы (L↔R) |

### transfer: перенос формы

1. Источник (OBJ/GLB, например экспорт SculptGL) приводится к системе модели; `align: auto` не
   трогает его, если габарит отличается меньше чем на 15 % и сдвиг меньше 15 % диагонали, иначе
   подгоняет по высоте и центру стоп (с предупреждением); `bbox` подгоняет всегда, `none` — никогда.
2. Каждая точка рабочей сетки ложится на поверхность источника: `project` бросает луч вдоль
   нормали в обе стороны и берёт попадание, если оно не дальше 1,5 расстояния до ближайшей точки
   (+0,2 % размера); промахи и далёкие попадания — ближайшая точка (`nearest` — всегда ближайшая).
3. Сдвиг умножается на `strength` и вес маски. У границы неполной области (вес меньше 1) и в
   двух кольцах за ней сдвиг сглаживается `seam_smooth` проходами.
4. UV, веса, риг и топология рабочей сетки не меняются, меняются только позиции.

Проверки: `transfer_max_dist_m` — наибольшее расстояние от вершин полного веса до источника,
`transfer_mean_dist_m` — среднее (предупреждения, пределы `tolerance_m` и его четверть). В
`stats.transfer` лежат и обратные расстояния (`cover_max`, `cover_mean`: от вершин источника до
рабочей сетки), по ним видно, не мельче ли рабочая сетка источника.

## Проверки

| Имя | Серьёзность | Смысл |
|---|---|---|
| `no_nan_verts` | ошибка | нет NaN в позициях |
| `sculpt_manifold` | ошибка | в сваренном виде не прибавилось открытых и неманифолдных рёбер (`symmetrize` вдвое умножает открытые края исходной стороны; после `remesh` допускается горсть рёбер тонких перекрытий) |
| `sculpt_uv_kept` | ошибка | при `keep_uv`: слои UV на месте, конечные, у точечных операций побитово прежние |
| `sculpt_rig_kept` | ошибка | при `preserve_rig`: кости, клипы, группы вершин, модификаторы арматуры, доля взвешенных вершин |
| `sculpt_changed` | предупреждение | что-то сдвинулось (иначе область промахнулась или суммы нулевые) |
| `sculpt_symmetric` | предупреждение | после `symmetrize` доля вершин с зеркальной парой ≥ 0,98; при `symmetry` на точечных операциях симметрия не хуже исходной |
| `transfer_max_dist_m`, `transfer_mean_dist_m` | предупреждение | расстояние до источника |

## Примеры

Конвейер (рост 1,8 м, голова на высоте 1,6 м):

```json
{"steps": [{"step": "sculpt", "params": {
  "symmetry": "x",
  "ops": [
    {"op": "inflate", "amount": 0.008,
     "region": {"type": "sphere", "center": [0, -0.08, 1.62], "radius": 0.12, "falloff": "smooth"}},
    {"op": "smooth", "iterations": 4,
     "region": {"type": "box", "center": [0, 0, 1.0], "extents": [0.5, 0.4, 0.3], "feather": 0.4}},
    {"op": "grab", "offset": [0, 0, 0.02],
     "region": {"type": "bone", "name": "mixamorig:LeftShoulder", "falloff": "linear"}},
    {"op": "relax", "iterations": 3}
  ]}}], "from": "latest"}
```

Сгладить всё и сохранить объём: `[{"op": "smooth", "iterations": 3}, {"op": "relax", "iterations": 3}]`
(это и есть пресет `sculpt_refine`).

Ремеш (UV стираются, риг и веса сохраняются): `{"ops": [{"op": "remesh", "voxel_size": 0.006}, {"op": "smooth", "iterations": 2}], "keep_uv": false}`.

Симметризация: `{"ops": [{"op": "symmetrize", "axis": "x", "direction": "+"}]}`.

Перенос формы из SculptGL:
`{"ops": [{"op": "transfer", "source_asset": "<UUID ассета с OBJ>", "region": {"type": "sphere", "center": [0, -0.1, 1.6], "radius": 0.2}}]}`.

## Как пользуется Claude через MCP

- `sculpt { assetId, ops, symmetry?, keep_uv?, preserve_rig?, params?, from?, wait?, timeoutSec? }` —
  запускает шаг на ассете (по умолчанию с `latest`), ждёт до 600 с и возвращает статус, выходы,
  проверки и сводку по операциям (сдвинутые точки, максимальный сдвиг, секунды). Новая версия
  ассета создаётся, старые не перезаписываются.
- `sculpt_transfer { assetId, source | sourceAsset, region?, method?, strength?, align?, seam_smooth?, … }` —
  `source` (путь к OBJ/GLB на этом компьютере) загружается в студию отдельным ассетом (`kind: prop`),
  затем запускается `transfer` с `source_asset`. Путь по HTTP шагу передавать нельзя (студия
  отклоняет пути на диске), поэтому файл превращается в ассет.
- Порядок: `forge_asset_show` (габариты, кости) → `sculpt` с небольшой областью → смотреть
  `preview.png` и проверки → при необходимости ещё одна версия. Размеры области Claude берёт из
  габаритов модели: голова примерно на 0,9 роста и выше, радиус области 0,06–0,15 м.

## Ограничения

- Регионы заданы в мировых осях модели, не локальных осях объекта. Поворот узла сетки учитывается.
- Разные объекты (голова и тело отдельными сетками) не свариваются между собой: шов между ними
  двигается каждым объектом независимо.
- Нормали затронутых сеток пересчитываются заново (угол `shade_auto_smooth_deg`), прежние
  пользовательские нормали теряются.
- `remesh` стирает UV, цвет вершин и текстуру. Цвет переносится шагом `cleanup` (`voxel_remesh_m`,
  запекание). Сетка с UV при `keep_uv: true` его не получит.
- `symmetrize` даёт зеркальной половине те же UV, что у исходной (острова перекрываются; для
  запекания развернуть заново), предупреждение попадает в `warnings`.
- `decimate` по области не даёт жёсткой границы: коллапс-децимация лишь удорожает схлопывание вне
  области. В тестах сфера: внутри области вершин остаётся меньше 60 %, снаружи — больше 95 %.
- Морф-таргеты (shape keys) сдвигаются вместе с базисом на тот же вектор; точечные операции их не пересчитывают заново.
- `bone` без группы вершин у сетки считается по расстоянию до кости в позе покоя.
- Сетки с нулевым определителем трансформа (нулевой масштаб) отклоняются.
- Детерминизм: случайности нет, повтор с теми же входами даёт те же позиции (QuadriFlow вызывается с `seed=0`).

## Замеры и тесты

`blender -b --factory-startup --python scripts/blender/tests/run_tests.py -- sculpt` — 23 теста:

- синтетика (сфера 0,5 м): `inflate` на 0,05 м поднимает средний радиус на 0,05 м (допуск 1 мм); область не двигает
  вершины вне круга (сдвиг < 1e-5 м); `smooth` держит центр масс (дрейф < 0,5 % радиуса); `relax`
  держит объём (12 проходов: +0,005 %), `smooth` на тех же 12 проходах теряет 15,8 %; `symmetrize` даёт долю зеркальных пар > 0,99; симметрия
  зеркалит смещение точно; `transfer` сферы на деформированную копию — расстояние до источника < воксель
  (0,02 м), для OBJ и GLB; `subdivide` по области не трогает нижнюю половину; `remesh` с UV отклоняется, без UV даёт замкнутую сетку;
- риг: на настоящем ассете библиотеки (`animated.glb`, 25 костей, 5 клипов, 29 510 вершин) операции с
  сохранением рига проходят за 2 с (с превью), `remesh` на 0,0033 роста даёт 299 тыс. вершин за 5 с, веса переезжают,
  `symmetrize` переносит 10 979 вершин левой группы в правую (L↔R) и обратно;
- синтетический риг из трёх костей: регионы по группе, по кости (с зеркальной группой и без неё), `symmetrize` с
  переворотом групп, `remesh` с перестройкой весов, `preserve_rig: false`.
