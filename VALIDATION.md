# Проверка от 9 октября 2026 — первоначальный pipeline 0.1

Сборка Vite проходит. Семь проверок схем, безопасности действий AI, связности workflow и интерполяции кадров проходят.

На этом компьютере проверено:

- RTX 4070, 12 ГБ VRAM; RAM около 64 ГБ.
- Официальный PNG-концепт Hunyuan3D → геометрия → настоящий GLB 2.0: около 15 секунд в быстром режиме. Исходник: [Tencent demo.png](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/assets/demo.png).
- Английское описание энергокапсулы → SDXL PNG → Hunyuan3D GLB 2.0: около 43 секунд. GLB около 4 МБ. Это два конкретных прогона, а не гарантия времени или качества для любого концепта.
- Ollama Qwen вернула корректную JSON-команду изменения материала; облачный провайдер при этом не использовался.
- Выбор деталей, параметры трансформации и материалов, ключевые кадры, сохранение локального проекта и восстановление результата из истории через интерфейс.
- Экспортированный GLB содержит 15 мешей и один анимационный клип с тремя каналами трансформаций.
- Запись WebM с частицами распознана ffprobe: VP9, 860×622, длительность около 1,97 секунды для двухсекундной сцены. Размер и реальная частота кадров зависят от окна и производительности браузера.
- Запуск и остановка через PowerShell-скрипты. Основной ComfyUI на 8188 и Ollama остаются доступны.
- Изменяющие запросы без клиентского заголовка или с чужим Origin отвергаются HTTP 403; API конфигурации не возвращает ключи.

Не проверено живыми запросами: OpenAI и Anthropic, поскольку пользователь не предоставлял API-ключей. Русский текстовый pipeline содержит вызов локальной LLM для перевода; полный замер текстового pipeline выше проведён на английском.

Первый запуск текстового теста сразу после перезапуска движка завершился сообщением о неготовом runtime. Повтор после готовности прошёл. Кнопка генерации теперь недоступна, пока status endpoint не подтвердит наличие модели.

Автоматический риг, генерация скелетной анимации, редактирование вершин и нейросетевые текстуры в эту проверку не входят: они пока не реализованы.

При восстановлении GLB без NORMAL-атрибута выявлено чёрное освещение меша. Исправлено вычислением нормалей при импорте и открытии проекта; восстановленный объект визуально проверен. Один SDXL-концепт оказался сеткой из нескольких видов вместо одного объекта. Промпт дополнен явным единственным видом и запретом коллажей; качество концепта всё равно требует оценки перед использованием модели.

Финальный прогон с локальным rembg/U2Net и режимом «Баланс» завершился за 110,6 секунды, включая подготовку фона. Подготовленный PNG имеет белый фон без тени. GLB — 7,66 МБ, 210504 вершины, 427730 треугольников. Объект импортирован, освещение нормалей проверено визуально, помещён в начало сцены и сохранён в проекте «AstraForge — тесты генерации». Удаление фона устранило лишнюю плоскость под объектом. Текстуры из концепта в эту геометрию не переносятся.


## Проверка 0.3 — текстуры, клипы, спрайты и Tripo

- 23 автоматические проверки проходят; Vite production build проходит.
- xatlas развернул 15 мешей манекена с сохранением атрибутов skin. Созданы четыре PBR-карты 512×512. После сохранения gzip-проекта и повторного открытия карты восстановились.
- Проекция изображения через depth/UV shader изменила 135255 пикселей карты цвета более чем на 8 единиц. Ошибок компиляции shader не наблюдалось. Это проверка проекционного pipeline на техническом манекене, а не оценка качества совпадения с концептом.
- Godot 4.7.2 импортировал запечённый GLB: 27 костей, 15 skinned meshes, три клипа Idle/Walk/ArmRaise. Walk изменяет LeftUpperLeg, ArmRaise изменяет LeftUpperArm. В составной сцене Godot переименовал кости с суффиксом _2 из-за повторяющихся имён других узлов; каналы по-прежнему работают.
- SpriteFrames загрузился: 24 анимации, Walk_dir0 — 24 кадра, ArmRaise_dir7 — 25 кадров, 128×128, alpha, loop для Walk. Во всех 584 кадрах есть непустое изображение; три атласа имеют alpha от 0 до 255.
- Интеграция Tripo API v3 проверена mock-fetch: параметры, front/left/back/right, task_ ID, перенос нескольких клипов, запрет опасных адресов и повторов неопределённой платной отправки. В браузере проверены вкладка, операции, отсутствие ключа и отключённый платный запуск. Живые Tripo-задачи не проверены — ключ не предоставлен.

Доказательства: GODOT-BAKED-VALIDATION.json, GODOT-SPRITE-VALIDATION.json, SPRITE-PIXEL-VALIDATION.json, REFERENCE-PROJECTION-VALIDATION.json и проверенные демонстрационные экспорты.

- Настоящая локальная генерация режима high (45 шагов, 512³) завершилась за 268,757 с на RTX 4070 12 ГБ: 826452 вершины, 1666042 треугольника, GLB 29912116 байт. Доказательство DETAILED-QUALITY-VALIDATION.json; результат Detailed-local-demo.glb. Увеличение плотности сетки не гарантирует восстановление неизвестных деталей по одному ракурсу. Этот меш высокополигональный и требует оптимизации для игры.
